## What this repo actually contains right now

VEXVortex is a **VEX Robotics stats app** (Supabase backend + native iOS client + Codemagic CI).

- `ios/` — full SwiftUI source (App/Features/Networking/Models/Persistence/Resources) plus `project.yml` (XcodeGen spec) and a generated app icon. **Unbuilt and unverified**: there is no Mac/Xcode in this environment, so nothing here has been compiled or run. `VEXVortex.xcodeproj` is not committed — it's generated by `xcodegen generate` (locally or in `codemagic.yaml`). See `ios/README.md`.
- `supabase/` — real migrations (`vex` schema: teams/seasons/events/event_teams/matches/rankings, RLS locked to read-only for anon/authenticated), `seed.sql`, and a `sync-events` Edge Function. **Unrun**: no Supabase project is linked, so the SQL has not executed against a real database. See `supabase/README.md`.
- `apps/admin/`, `infra/`, `security/AGENTS.md`, `PROMPT_MAIN_BUILD.md`, `PROMPT_TAILSCALE_ADMIN_APP.md`, `PROMPT_SECURITY_AUDIT.md` — **legacy**, from an earlier, unrelated project this repo used to hold (a self-hosted Tailscale homelab appliance). Pending move to a separate repo. Do not follow their instructions for VEXVortex work — see the banner at the top of each file.

Before claiming something is "working," "verified," or "secure": this codebase has never been built, run, or tested against a live Supabase project. Say so plainly instead of implying it's been confirmed.
